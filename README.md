# Land Radar

เว็บ React สำหรับรวบรวมประกาศขายทอดตลาดกรมบังคับคดี แล้วค้นพิกัดแปลงจาก LandsMaps แสดงรายการและแผนที่พร้อมภาพหลักฐาน ใช้งานในเครื่อง Windows นี้ที่ **http://127.0.0.1:5080**

## เปิดใช้งาน

ดับเบิลคลิก `Start.cmd` แล้วเปิด http://127.0.0.1:5080 หากเบราว์เซอร์ไม่เปิดเอง เก็บหน้าต่างโปรแกรมไว้ระหว่างใช้งาน กด Ctrl+C ในหน้าต่างเพื่อหยุด

เครื่องนี้ตั้งค่า PostgreSQL ไว้แล้ว ฐานข้อมูลชื่อ `led_radar` และ schema `land_radar` รหัสผ่านอยู่ใน `server/appsettings.Local.json` ซึ่งไม่รวมใน Git และไม่ถูกส่งไป frontend

หากแก้ React ให้รัน `Start.cmd --build` เพื่อ build ใหม่ ต้องหยุด server เดิมก่อนเริ่มอีกรอบ

## ใช้งาน

1. เลือกจังหวัด อำเภอ ตำบล ประเภททรัพย์ ราคา และพื้นที่ ตัวเลือกอ่านสดจากฟอร์มต้นทาง
2. ค่าเริ่มต้น: เชียงใหม่ พื้นที่รวม **มากกว่า 2 ไร่** และราคาประเมิน **ต่ำกว่า 4 ล้านบาท** (เพดาน 3,999,999.99 บาท)
3. ตั้งชื่อชุดการค้นหาแล้วกด **บันทึกเงื่อนไขนี้** เพื่อสร้าง bookmark
4. กรอกรหัสยืนยันที่เห็นในภาพ แล้วกด **Retrieve ข้อมูล** โปรแกรมไม่ได้อ่าน/แก้ CAPTCHA อัตโนมัติ
5. โปรแกรมอ่านทุกหน้าที่ต้นทางส่งมา ข้ามแถวสีแดง เปิดหน้ารายละเอียด และบันทึกภาพเต็มหน้า
6. ค้น LandsMaps ด้วยจังหวัด อำเภอ และเลขโฉนดแต่ละใบ โดยใช้การค้นหาปกติผ่านเบราว์เซอร์ ไม่ต้องมีบัญชีในการทดสอบวันที่ 12 พฤศจิกายน 2569
7. แผนที่แสดงเฉพาะพิกัดที่หาได้จริง กดรายการหรือหมุดเพื่อเปิดรายละเอียดและภาพประกาศ
8. เปิดผลเก่าจาก **ประวัติ** ได้โดยไม่ต้องดึงใหม่ และส่งออกข้อมูล JSON ได้

## ข้อมูลที่เก็บ

- ประเภททรัพย์ จังหวัด อำเภอ ตำบล เลขโฉนด
- เนื้อที่ไร่/งาน/ตารางวา และพื้นที่รวมเป็นตารางวา
- ราคาประเมิน วันประมูลทั้งหมดตามประกาศ (พ.ศ.)
- พิกัดจาก LandsMaps แยกตามเลขโฉนด กรณีหนึ่งรายการมีหลายโฉนด
- ภาพประกาศ ภาพหน้าผลค้นหา ภาพ LandsMaps เวลาเก็บข้อมูล และสถานะข้อผิดพลาด
- ตัวกรองที่ใช้และจำนวนหน้าที่อ่าน แถวทั้งหมด แถวสีแดง และแถวที่ไม่ผ่านเกณฑ์

ข้อมูลเก็บใน PostgreSQL แบบ JSONB ที่ `land_radar.jobs` และ `land_radar.bookmarks` ภาพ PNG เก็บใน `server/data/evidence/` ให้สำรองทั้งฐานข้อมูลและโฟลเดอร์ภาพ

## ความถูกต้องและข้อจำกัด

- พื้นที่ “มากกว่า” คำนวณจาก `ไร่ × 400 + งาน × 100 + ตารางวา` ตัวดึงขยายช่วงค้นหาของคอลัมน์ไร่ก่อนกรองซ้ำในโปรแกรม เพื่อไม่ให้พลาด 2 ไร่ 1 งาน เป็นต้น เงื่อนไขเท่ากับ/น้อยกว่าของแต่ละหน่วยใช้ความหมายเดียวกับเว็บต้นทาง
- ราคาที่ดึงคือ **ราคาประเมิน** ไม่ใช่ราคาชนะประมูลหรือราคาเริ่มต้นของแต่ละนัด
- พิกัด LandsMaps เป็นตำแหน่งโดยสังเขปจากบริการกรมที่ดิน ไม่ใช่การยืนยันขอบเขตรังวัด
- ไม่ใช้จุดศูนย์กลางตำบล/อำเภอแทนแปลงที่หาไม่พบ รายการที่ไม่พบพิกัดแสดงสถานะแยก และลองค้นพิกัดซ้ำได้
- ตรวจจังหวัด อำเภอ และตำบลของผล LandsMaps เทียบกับประกาศ ชื่ออำเภอเก่าบางรูปแบบถูกปรับให้ตรงกัน แต่ไม่เดาสถานที่ด้วย fuzzy matching
- LandsMaps ปิดบังเลขโฉนดบางหลักในผลลัพธ์ จึงเก็บเลขโฉนดจากประกาศ พร้อมหลักฐานผลการค้นหาด้วยเลขนั้น
- เอกสารสิทธิที่ไม่ใช่โฉนด หรือรูปแบบเลขที่อ่านไม่ได้ ต้องตรวจสอบด้วยตนเอง
- ตัวกรองและตัวเลือกใหม่จะอ่านจากฟอร์มได้อัตโนมัติ แต่ถ้าต้นทางเปลี่ยนโครงสร้าง HTML, ขั้นตอน, หรือการยืนยันตัวตนอย่างมีนัยสำคัญ ต้องปรับตัวเชื่อมต่อ โปรแกรมจะหยุด/แจ้งข้อผิดพลาด แทนรายงานว่าดึงครบ
- งานที่มีข้อผิดพลาดหรือพิกัดขาดแสดง `partial` งานที่ถูกปิดกลางคันแสดง `interrupted` ผลที่บันทึกแล้วไม่หาย
- หาก LandsMaps โหลดหน้าค้นหาไม่ได้ โปรแกรมหยุดค้นพิกัดรอบนั้นและเก็บรายการที่ยังไม่ได้ค้นไว้ กดค้นพิกัดซ้ำได้ภายหลังโดยไม่ต้องดึงประกาศใหม่ ความล้มเหลวในการโหลดแยกจากผล “ไม่พบแปลง”
- ทำงานทีละงานและเว้นช่วงระหว่างรายการ งานขนาดใหญ่อาจใช้เวลาหลายนาที

## เทคโนโลยี

React + TypeScript + Vite, Leaflet + OpenStreetMap, Node.js + Express + Playwright, PostgreSQL

โค้ด backend แยก `domain`, `application`, `infrastructure`, `presentation` และ composition root โดย application รับ dependency ผ่าน ports รายละเอียดอยู่ใน [docs/architecture.md](docs/architecture.md) แนวทางการทำงานและความต้องการของเจ้าของโครงงานบันทึกใน [AGENTS.md](AGENTS.md)

เริ่มทดลอง C#/.NET ตามที่ขอและ build ผ่าน แต่ Windows Application Control บล็อก DLL ที่คอมไพล์ในเครื่อง จึงเปลี่ยน backend เป็น Node.js ตามสิทธิ์ที่ผู้ใช้อนุญาตให้เลือกเทคโนโลยีที่รันได้ ไม่ได้แก้/ปิดการตั้งค่าความปลอดภัย ระบบ build ใช้ Rollup รุ่น WebAssembly เพื่อรองรับข้อจำกัด native module ในเครื่องนี้

## ตั้งค่าเครื่องอื่น

ติดตั้ง Node.js LTS และ PostgreSQL แล้วสร้างฐานข้อมูล `led_radar` ตั้งค่า `server/appsettings.Local.json`:

```json
{
  "ConnectionStrings": {
    "Postgres": "Host=localhost;Port=5432;Database=led_radar;Username=postgres;Password=YOUR_PASSWORD"
  }
}
```

รัน `Start.cmd --build` เพื่อติดตั้ง dependencies, build frontend, และติดตั้ง Chromium สำหรับตัวดึง จากนั้นรันได้ด้วย `Start.cmd`

โปรแกรมฟังเฉพาะ `127.0.0.1` ไม่เปิดให้เครื่องอื่นในเครือข่าย ไม่เหมาะสำหรับเปิดเป็นเว็บสาธารณะโดยไม่มีระบบบัญชีผู้ใช้

## ตรวจสอบ

```powershell
cd server
npm test
npm run format:check
cd ../client
npm run build
```

ใช้ `npm run format` ใน `server` เพื่อจัดรูปแบบด้วย Prettier ก่อน commit

`node tests/smoke-lands.mjs` จากโฟลเดอร์โครงการ ทดสอบการค้น LandsMaps จริงด้วยโฉนดตัวอย่างที่ตรวจสอบแล้ว และบันทึกภาพใน evidence โดยไม่สร้างรายการทรัพย์จำลองในฐานข้อมูล
